# ⚾ KBO 뉴스 멀티모달 감성분석 (찹쌀떡팀)

야구(KBO) 뉴스 기사를 대상으로 텍스트와 이미지를 함께 활용해 카테고리 분류 및 감성 분석을 수행하는 빅데이터프로그래밍 캡스톤 프로젝트입니다.

## 📌 프로젝트 개요

KBO 관련 뉴스 기사는 특정 도메인(야구)의 용어와 맥락이 강하게 반영되어 있어, 일반적인 감성분석 모델을 그대로 적용하기 어렵습니다. 본 프로젝트는 뉴스의 **텍스트(기사 본문)** 와 **이미지(기사 첨부 사진)** 를 함께 활용한 멀티모달 접근을 통해, 기사 카테고리 분류와 감성 분석 성능을 개선하는 것을 목표로 합니다.

## 👥 팀 구성 및 역할

| 이름 | 담당 |
|---|---|
| 안성민 (팀장) | 카테고리별 라우팅 감성 분류 아키텍처, 앙상블 |
| 김규원 | 크롤링/전처리, 카테고리 실험 (feat/gyuwon) |
| 유범준 | BERT / KoCLIP |
| 김동환 | ResNet / TF-IDF |
| 이윤서 | KoBART / 평가지표 / 보고서 |

## 🖥️ 실험 환경

- **공식 실험 환경**: RunPod RTX 3090
- RTX 4060(팀원 로컬 환경)은 재현성 검증용으로만 사용

## 🔬 진행 단계

### Stage 1 — 베이스라인 모델 구축 (완료)

각 모달리티별 베이스라인 성능을 측정하고, 멀티모달 결합(Late Fusion)의 효과를 검증했습니다.

| 모델 | 결과 |
|---|---|
| TF-IDF (카테고리 분류) | F1 = 0.8287 |
| BERT (감성 분류, 공식) | Accuracy = 0.7383 / Macro-F1 = 0.7404 |
| Late Fusion (α=0.85) | F1 = 0.7395 |
| ResNet (이미지 단독) | F1 = 0.4536 |

**핵심 발견**
- 이미지 모달리티 단독으로는 성능이 불충분함
- 카테고리 전처리 품질이 전체 성능에 직결됨
- KBO 도메인 특수성으로 인해 TF-IDF가 BERT보다 우수한 경우가 있음

### Stage 2 — 카테고리 중심 개선 (진행 중)

Stage 1 결과를 바탕으로 카테고리 분류 품질 개선에 집중하고 있습니다.

**김규원 담당 (`feat/gyuwon` 브랜치)**
- **1안**: `categoryNums.py` — BERT ablation (v1 → v2 → v3, v3는 키워드 확장)
- **2안**: `catFeature.py` — BERT 임베딩(768) + 카테고리 임베딩(32) concat 후 감성 분류 A/B 비교
- **3안**: `gyuwonIdea/` (8개 파일) — centroid + 코사인 유사도 기반 빠른 분류, Sequential/Random/Stratified 비교, TF-IDF vs BERT 임베딩 비교
  - 1, 2안은 RunPod 필요 / 3안 중 TF-IDF 파트는 로컬 실행 가능

**안성민 담당**
- 카테고리별 라우팅 감성 분류 아키텍처 설계
